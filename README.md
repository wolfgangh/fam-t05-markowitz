# FAM T05 – zwei Anlagen und Diversifikation

Interaktives Labor zur Einheit T05, Kurs Financial Markets and Asset Management (FAM), OTH Regensburg.
Fall: Ein Software-Anbieter zeigt dem Committee eine Optimierung. Zwei Anlagen: DAX-ETF und Gold-ETC.

## Start

Lokal: Installation, Entwicklung, Bau, Vorschau.

Im package.json: Skript dev, Skript build (tsc plus vite, Ordner dist), Skript preview.

## Didaktische Absicht

Situation zuerst. Dann Handweg mit drei leeren Feldern (Gewicht DAX, Gewicht Gold, Risiko des MVP). Erst nach dem Bestätigen öffnen sich das Zwei-Anlagen-Modell, die Kipp-Demo und die Krise. Soll: 40 % / 60 % / 9,60 %. Das MVP braucht keine Renditeprognosen. Für rho kleiner als 1 liegt das Portfoliorisiko unter dem gewichteten Mittel.

Sie-Form. de-DE-Zahlen. Kein Marktblock.
